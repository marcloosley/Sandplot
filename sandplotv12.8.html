Install App / Add to Mobile Home Screen

Ready for 1-Tap App Installation

Your browser supports installing SandPlot directly as a standalone app window.

SandPlot now includes embedded mobile web-app metadata, touch icons, and standalone full-screen tags inside this HTML file. To add it to your phone or tablet home screen:

🍏 iPhone / iPad (Safari)

Open SandPlot over https:// (e.g. GitHub Pages, Netlify, intranet, or SharePoint/Drive web host), tap the Share icon [↑] at the bottom/top of Safari, and tap Add to Home Screen.

🤖 Android (Chrome / Edge)

Open SandPlot in Chrome or Edge, tap the ⋮ browser menu in the top-right corner, and tap Add to Home screen or Install app.

Tip (https:// vs file://): Mobile OS browsers only enable "Add to Home Screen" when the HTML file is opened via an https:// URL (such as a private GitHub Pages / Cloudflare / Netlify link or local Wi-Fi server), rather than directly from the phone's Downloads file viewer.
